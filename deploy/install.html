한국어

공개 데모는 미리 계산된 기록만 제공합니다. Python 3.10 이상과 Git을 설치한 컴퓨터에서 아래 명령을 실행하세요. 브라우저로 http://127.0.0.1:8765 를 열면 코드를 편집하고 실행할 수 있습니다. 실행한 Python은 컴퓨터의 사용자 권한으로 동작하므로 신뢰하는 파일만 실행하세요.

English

The public demo provides precomputed recordings. On a computer with Python 3.10+ and Git, run the commands below and open http://127.0.0.1:8765 to edit and execute code. Python runs with your account's permissions; only execute trusted files.

日本語

公開デモは事前計算された記録を提供します。Python 3.10 以上と Git を導入したコンピューターで以下を実行し、http://127.0.0.1:8765 を開くとコードを編集・実行できます。Python はユーザー権限で動作するため、信頼できるファイルのみ実行してください。

macOS / Linux

git clone https://github.com/yunsalmon/factory-ide.git
cd factory-ide
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python server.py --host 127.0.0.1 --port 8765

Windows PowerShell

git clone https://github.com/yunsalmon/factory-ide.git
cd factory-ide
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python server.py --host 127.0.0.1 --port 8765
