Factory Studio 시작하기

개발자는 Python으로, 제조 플래너는 공정도로 같은 모델을 편집합니다.

  1. 설계: 머신·경로를 클릭해 속성을 수정하세요. MODEL 선언부가 갱신되고 사용자 함수는 보존됩니다.
  2. 프로그래밍: MODEL은 Python 리터럴로 작성하세요. choose_candidate와 processing_time 함수에서 상세 로직을 구현합니다. 코드 수정은 공정도에 자동 반영됩니다.
  3. 실행: 실행 버튼 또는 Ctrl+Enter. 실제 SimPy가 로컬 Python에서 실행됩니다. 실행 중에는 버튼으로 중지할 수 있습니다.
  4. 관찰: 재생·일시정지·다음 이벤트 또는 타임라인으로 기록을 탐색합니다. ‘선택마다 멈춤’은 의사결정 기록 재생을 멈춥니다.
  5. 이해: 이벤트를 클릭하면 선택 후보와 이유가 표시됩니다. 로트를 선택하면 해당 경로와 이력만 강조됩니다.
  6. 저장: Ctrl+S로 Python 파일 다운로드. 브라우저에도 자동 저장됩니다. Python 파일을 열어 이어서 작업하세요.

모델 의미: 머신 1대는 한 번에 로트 하나를 처리합니다. 연결 경로로 직렬·병렬 구성을 표현하며, 공정·라인은 머신의 그룹입니다. 경로 우선순위는 낮은 숫자가 먼저입니다. 출력 대기 공간은 무제한이며, 이동 중 목적지 머신은 예약됩니다.

실행 범위: 로트 분할·병합·배치 처리와 LLM 연동은 포함하지 않습니다. 재생은 기록된 제조 이벤트 단위이며 Python 줄 단위 디버거가 아닙니다.

열어 실행한 Python은 이 컴퓨터의 사용자 권한으로 동작합니다. 신뢰하는 파일만 실행하세요. 초기 설치 이후 인터넷 없이 사용할 수 있습니다.
